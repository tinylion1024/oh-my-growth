# Safety Boundaries

安全边界机制，避免高风险建议。

## 硬边界领域

### 财务风险 (financial)

**触发词**：投资、融资、估值、定价、重大支出、股权、债权、并购

**响应规则**：
- 提供决策框架，不提供最终投资建议
- 明确声明"仅供参考，不构成投资建议"
- 建议咨询专业财务顾问

**警告模板**：
```
⚠️ 财务风险提示
本分析为决策支持框架，不构成最终投资建议。
重大财务决策建议咨询：
- 注册会计师
- 投资顾问
- 法务顾问
```

### 法律风险 (legal)

**触发词**：合规、合同、知识产权、竞争法、监管、诉讼、劳动法

**响应规则**：
- 提供风险清单和准备问题
- 不提供法律建议或合规结论
- 建议咨询律师

**警告模板**：
```
⚠️ 法律风险提示
本分析识别了潜在法律风险点，但不构成法律意见。
建议咨询：
- 公司法务部门
- 外部法律顾问
- 行业监管机构
```

### 监管风险 (regulatory)

**触发词**：牌照、数据合规、隐私保护、行业监管、反垄断、税务

**响应规则**：
- 提供合规检查清单
- 不提供合规结论
- 建议咨询专业机构

**警告模板**：
```
⚠️ 监管合规提示
本分析提供合规检查框架，具体合规结论需专业机构评估。
建议咨询：
- 行业监管机构
- 合规咨询公司
- 数据保护官
```

### 运营风险 (operational)

**触发词**：裁员、重大组织变更、品牌危机、公关危机、核心业务调整

**响应规则**：
- 提供分析框架和选项
- 不提供执行建议
- 建议咨询专业顾问

**警告模板**：
```
⚠️ 重大运营决策提示
本分析提供决策框架，具体执行建议需专业顾问评估。
建议咨询：
- 人力资源顾问
- 公关顾问
- 战略顾问
```

## 响应规则

### 通用规则

1. **检测触发**：当用户输入包含任一触发词时，激活对应安全边界
2. **警告优先**：在输出开头添加警告声明
3. **评分限制**：不让高评分覆盖硬安全边界
4. **建议保守**：高风险案例的行动建议必须可逆、保守、审查导向

### 检测流程

```
用户输入
    ↓
关键词扫描（匹配触发词）
    ↓
激活对应安全边界
    ↓
添加警告声明
    ↓
调整建议置信度
    ↓
输出结果
```

### 置信度调整

| 风险等级 | 置信度上限 | 建议强度 |
|---------|-----------|---------|
| 财务风险 | Medium | 框架建议 |
| 法律风险 | Low | 风险清单 |
| 监管风险 | Low | 检查清单 |
| 运营风险 | Medium | 选项分析 |

## 报告要求

高风险案例必须包含以下章节：

### 1. 风险边界

```markdown
## 风险边界

本分析涉及以下高风险领域：
- [ ] 财务风险
- [ ] 法律风险
- [ ] 监管风险
- [ ] 运营风险

⚠️ 本报告仅为决策支持，不构成专业建议。
```

### 2. 专业审查触发条件

```markdown
## 专业审查建议

建议在以下情况下咨询专业顾问：
- 涉及金额超过 [X] 元
- 可能影响 [X] 人以上
- 涉及 [具体法律/监管领域]
- 需要签署具有法律约束力的文件
```

### 3. 低风险下一步

```markdown
## 可安全执行的下一步

以下行动风险较低，可先行执行：
1. [信息收集行动]
2. [分析评估行动]
3. [咨询准备行动]
```

### 4. 不可逆行动前证据要求

```markdown
## 不可逆行动前必须收集的证据

在执行以下不可逆行动前，必须：
- [ ] 获得专业顾问书面意见
- [ ] 完成风险评估报告
- [ ] 获得决策委员会批准

不可逆行动清单：
- [具体行动列表]
```

## 集成方式

### 在 Agent 中使用

```yaml
# 在 skeptic-agent.md 中
safety_check:
  reference: "references/safety-boundaries.md"
  
  check_triggers:
    - financial_keywords
    - legal_keywords
    - regulatory_keywords
    - operational_keywords
  
  on_detection:
    - add_warning_banner
    - cap_confidence
    - require_professional_review
```

### 在 SKILL.md 中配置

```yaml
safety_protocol:
  enabled: true
  check_triggers: true
  block_high_risk_recommendations: true
  require_professional_disclaimer: true
  domains:
    - financial
    - legal
    - regulatory
    - operational
```

## 集成方式

在Narrative Agent中自动调用可视化模块：

```python
def render_output(analysis_result):
    """
    渲染带可视化的输出
    """
    output = []
    
    # 漏斗图
    if analysis_result.get("funnel"):
        output.append(render_funnel(analysis_result["funnel"]))
    
    # ROI图
    if analysis_result.get("roi"):
        output.append(render_roi_chart(analysis_result["roi"]))
    
    # Agent对比
    if analysis_result.get("agent_scores"):
        output.append(render_agent_comparison(analysis_result["agent_scores"]))
    
    # 风险矩阵
    if analysis_result.get("risks"):
        output.append(render_risk_matrix(analysis_result["risks"]))
    
    return "\n\n".join(output)
```

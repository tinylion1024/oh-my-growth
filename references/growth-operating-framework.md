# Growth Operating Framework - 通用增长操作框架

这个框架用于把增长问题先放回业务经营视角，再进入案例、玩法和实验层。

## 1. 先看增长目标

增长不只等于新增用户，还等于新增用户能否留下、付费、复购和持续创造长期价值。

可用一个简化表达来理解：

```text
增长结果 = 用户规模 × 长期价值
```

这意味着任何增长判断都至少要同时回答两个问题：

- 用户是怎么进来的
- 用户进来之后为什么会留下、复访、付费或带来更多用户

## 2. 两条主业务过程

### 用户获取

适合处理这些问题：

- 冷启动获客
- 渠道拉新
- 内容增长
- 投放放大
- 裂变传播

关注重点：

- 用户来源是否稳定
- 获客成本是否可控
- 新用户质量是否达标
- 增长动作能否复制

### 用户深耕

适合处理这些问题：

- 激活
- 留存
- 复购
- 升级付费
- 召回

关注重点：

- 用户是否真正获得核心价值
- 留存链路哪里断了
- 付费触发点是否成立
- 生命周期价值是否在提升

## 3. 三段式阶段判断

### 产品验证期

典型特征：

- 还在找可复制的主路径
- 预算和人力有限
- 更关心留得住的首批用户，而不是表面规模

策略重心：

- 找高意向种子用户
- 验证核心价值是否成立
- 把转化和留存主链路打通
- 控制试错范围，避免同时铺太多渠道

### 增长放大期

典型特征：

- 已有初步成立的价值主张或渠道
- 需要把单点有效动作变成稳定系统
- 开始面临效率、协同和节奏问题

策略重心：

- 放大已验证的主抓手
- 建立漏斗追踪和归因闭环
- 优化激活、留存、裂变和转化协同
- 用实验逐步扩大投入

### 规模经营期

典型特征：

- 已进入规模化经营
- 需要平衡收入、效率、品牌和长期价值
- 单一抓手边际收益下降

策略重心：

- 精细化经营和结构优化
- 关注 LTV、回收周期和利润质量
- 做更严格的资源分配
- 寻找新的增长曲线或新增量来源

## 4. 北极星指标判断法

北极星指标不是“最大的数”，而是当前阶段最值得围绕它做资源分配的那个指标。

一个合格的北极星指标通常满足：

- 代表用户真正获得了核心价值
- 能被持续追踪，不依赖偶发事件
- 能被团队行动直接影响
- 和业务结果有明确关联

同时要配一条约束线：

- 上限指标：你希望被持续拉升的核心指标
- 下限指标：你绝不能破坏的底线指标

常见组合示例：

- 获客问题：新增高意向用户数 + CAC 上限
- 激活问题：首次价值达成率 + 流失率
- 留存问题：7日/30日留存 + 用户投诉或退订
- 变现问题：付费转化率或 ARPU + 留存底线
- 裂变问题：邀请转化率或 K 因子 + 用户质量底线

## 5. 策略环

面对增长问题时，建议统一走这四步：

### 识别机会

- 当前阶段是什么
- 主业务过程是获取还是深耕
- 用户旅程卡点在哪
- 哪个指标最值得先救

### 制定策略

- 明确主抓手
- 给出建议做和先别做
- 排出优先级
- 说明为什么现在做

### 验证策略

- 设计最小实验
- 设定成功信号和停止信号
- 建立数据追踪与归因口径

### 发展策略

- 复盘实验结果
- 决定放大、迭代或停止
- 判断是否切换阶段或开启新曲线

## 6. 用户旅程视角

任何增长问题都可以映射到用户旅程某一段，而不是只看渠道或玩法名词。

一个最小旅程拆解可以是：

```text
认知 → 到达 → 注册 → 激活 → 留存 → 付费 → 分享/复购
```

排查顺序建议：

1. 先找断点最明显的一段
2. 再判断是流量质量问题、产品体验问题还是激励设计问题
3. 最后才去匹配具体玩法

## 7. 数据与归因要求

没有追踪和归因，增长就只能停留在“感觉有效”。

最小数据要求：

- 主指标有当前值、目标值和观察周期
- 过程指标与主指标的关系清楚
- 渠道、内容、产品动作至少能做基础归因
- 实验前后口径一致

## 8. 如何和当前项目结合

在这个项目中，这套框架适合作为上层路由：

1. 先做阶段判断
2. 再判断当前属于用户获取还是用户深耕
3. 再定义北极星指标和约束线
4. 再进入案例、玩法、理论检索
5. 最后输出优先级、建议做/不做和实验计划

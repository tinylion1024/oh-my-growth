# omg - oh-my-growth 别名

这是 `/oh-my-growth` 的缩写别名，提供相同的功能。

## 快速开始

```
/omg diagnose 我的产品日活下降20%，该怎么办？
/omg assess 我们准备做裂变，先评估可行性
/omg design SaaS产品如何设计变现策略？
/omg match 游戏化留存案例
```

## 可用命令

| 命令 | 用途 |
|------|------|
| `/omg diagnose` | 诊断+优先级+实验建议 |
| `/omg assess` | 评估可行性 |
| `/omg design` | 策略设计 |
| `/omg match` | 案例匹配 |
| `/omg learn` | 学习路径 |
| `/omg cold-start` | 冷启动场景 |
| `/omg retention` | 留存策略 |
| `/omg monetization` | 变现策略 |
| `/omg referral` | 裂变策略 |

# Guide Agent 测试用例

## 测试概览

测试 Guide Agent 交互式引导的能力。

---

## 测试用例 1：信息收集引导

### 输入

```json
{
  "user_input": "我想做增长",
  "clarity_score": 20,
  "missing_info": ["目标", "行业", "阶段", "约束"]
}
```

### 预期输出

```json
{
  "guidance": {
    "current_status": "信息不足，需要澄清以下问题",
    "questions": [
      "您所在的行业是什么？（如电商、SaaS、教育等）",
      "您的产品处于什么阶段？（冷启动/增长期/成熟期）",
      "您具体想解决什么问题？（获客/留存/变现等）"
    ],
    "example_answers": {
      "行业": "电商",
      "阶段": "增长期，月活10万",
      "问题": "复购率低，仅15%"
    }
  }
}
```

### 验证点

- [ ] 识别缺失信息
- [ ] 提供清晰问题
- [ ] 给出示例引导

---

## 测试用例 2：决策引导

### 输入

```json
{
  "user_input": "我有两个方案，不知道选哪个",
  "options": [
    {"name": "方案A：内容营销", "effort": "中", "impact": "长期"},
    {"name": "方案B：付费投放", "effort": "低", "impact": "短期"}
  ]
}
```

### 预期输出

```json
{
  "guidance": {
    "decision_framework": "建议根据当前紧迫程度和资源情况选择",
    "comparison": {
      "时间敏感度": "方案B见效快",
      "预算敏感度": "方案A成本低",
      "可持续性": "方案A长期收益更高"
    },
    "suggested_questions": [
      "您的预算上限是多少？",
      "多长时间内需要看到效果？",
      "团队是否有内容创作能力？"
    ],
    "recommendation": "如果预算允许，建议方案A+B结合：用小预算投放验证，同时布局内容"
  }
}
```

### 验证点

- [ ] 提供决策框架
- [ ] 对比分析
- [ ] 建议组合方案

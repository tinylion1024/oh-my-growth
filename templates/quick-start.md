# 快速启动模板

> 复制以下模板，填充您的信息，然后使用 `/growth-master-skill <模式>` 触发

---

## 📋 通用完整模板

```
/growth-master-skill assess

【产品类型】[电商/SaaS/社交/内容/金融/教育/AI工具/其他]
【产品名称】[您的产品名称]
【当前阶段】[0-1 / 1-10 / 10-100]
【核心问题】[获客/激活/留存/变现/裂变]
【用户规模】[当前用户数量]
【核心指标】[您最关注的指标及当前数值]
【主要挑战】[详细描述您面临的增长挑战]
【已有尝试】[您已经尝试过什么方法？效果如何？]
【资源约束】[预算/人力/时间等约束]
【期望目标】[您希望达到什么效果？]

请评估我的增长方向是否可行，并给出具体建议。
```

## 使用提示

1. **选择模板**：根据您的场景选择合适的模板
2. **填充信息**：如实填写您的实际情况
3. **触发技能**：使用 `/growth-master-skill <模式>` 触发
4. **跟进反馈**：根据输出调整策略

### 模式说明

| 模式 | 用途 | 输出 |
|------|------|------|
| `assess` | 评估机会是否可行 | 快速判断 + 建议 |
| `design` | 设计增长策略 | 策略方案 + 玩法组合 |
| `learn` | 学习增长知识 | 学习路径 + 资源 |
| `audit` | 审计现有方案 | 风险识别 + 改进建议 |
| `match` | 匹配成功案例 | 案例列表 + 可复制点 |

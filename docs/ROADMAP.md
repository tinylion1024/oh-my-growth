# Public Roadmap

This roadmap communicates active direction, not a delivery guarantee. Priorities are
reordered when user evidence, maintainer capacity, or platform contracts change.

## Now: trust and contribution

- Publish a GitHub release that matches the repository's versioned package metadata.
- Collect anonymized, reproducible user cases with explicit evidence tiers.
- Make first contributions easy through small, well-scoped GitHub issues.
- Keep Claude Code, OpenClaw, Hermes, and standalone CLI installation contracts verified.

## Next: retrieval quality and reuse

- Improve case and play ranking with stronger semantic and evidence signals.
- Expand vertical examples only where real user requests show a coverage gap.
- Improve public-safe output formats for team updates and community sharing.

## Later: integration and collaboration

- Evaluate package-registry distribution after trusted publishing is configured.
- Evaluate additional agent ecosystems based on maintained install contracts.
- Explore collaborative case libraries only after feedback demonstrates sustained demand.

## How to influence it

- Vote with a reaction or comment on an open issue.
- Submit a sanitized case through the Growth Case Contribution issue form.
- Open a focused proposal with the problem, expected outcome, and evidence.

# Growth Master 最佳实践

## 问题输入最佳实践

### 1. 提供完整信息（现状清晰度）

**❌ 不好的输入**（清晰度评分：~20分）：
```
我想增长
```

**✅ 好的输入**（清晰度评分：~70分）：
```
我们是一个SaaS协作工具，有5000注册用户 (observed)，月活800 (observed)。
想通过邀请裂变增长，预算有限 (estimated: 5万以内)。
主要挑战：用户不愿意分享 (observed: 分享率仅2%)
```

### 清晰度提升技巧

| 维度 | 提升方法 |
|------|----------|
| 目标与成功标准 | 明确量化目标：提升DAU到1200（+50%）|
| 事实与证据 | 标记数据来源：(observed)、(estimated)、(assumed) |
| 阶段判断 | 说明产品阶段：0-1验证期 / 1-10增长期 / 10-100规模化 |
| 稀缺资源 | 明确约束：预算5万、团队3人、时间3个月 |
| 硬约束 | 列出不可逾越的限制：不能使用积分商城 |
| 利益相关者 | 说明决策者：CEO最终拍板 |
| 重复模式 | 提供历史经验：上次裂变K因子0.5 |

### 2. 明确核心问题

**❌ 模糊的问题**：
```
用户增长不好
```

**✅ 明确的问题**：
```
问题：用户注册后不激活
数据：注册→激活转化率仅15%
目标：提升到30%以上
```

### 3. 提供约束条件

```
【预算】5万元以内
【人力】团队3人
【时间】希望3个月内见效
【已有尝试】做过简单推荐，效果不好
```

## 模式选择最佳实践

### Fast Scan vs Decision BRD

| 场景 | 推荐模式 |
|------|----------|
| 快速判断方向 | Fast Scan |
| 需要正式审批 | Decision BRD |
| 设计具体方案 | Strategy Design |
| 寻找参考案例 | Case Match |

### 何时使用多模式组合

```
第一步：Fast Scan
快速评估方向是否可行

↓ 如果可行

第二步：Strategy Design
设计具体策略

↓ 如果需要投入

第三步：Decision BRD
生成正式决策文档
```

## Agent使用最佳实践

### 理解Agent视角

不同Agent有不同的"偏见"：

| Agent | 默认视角 | 关注点 |
|-------|----------|--------|
| Growth Agent | 乐观 | 增长可能性 |
| Skeptic Agent | 悲观 | 风险和假设 |
| ROI Agent | 理性 | 投资回报 |
| Execution Agent | 务实 | 可执行性 |

### 关注分歧

当Agent产生分歧时，往往说明：

1. 证据不足，需要更多信息
2. 存在隐藏风险
3. 需要小实验验证

**示例**：
```
Growth Agent：可行性高，建议推进
Skeptic Agent：因果链薄弱，风险高

→ 结论：推荐先做小规模实验验证假设
```

### 置信度解读

| 置信度 | 建议行动 |
|--------|----------|
| High | 可以决策推进 |
| Medium | 建议先做小实验 |
| Low | 需要更多研究 |

## 证据分级最佳实践

### 使用证据分级评估建议可靠性

每个案例、玩法、理论都有证据分级：

| 等级 | 可靠性 | 使用建议 |
|------|--------|----------|
| A | 学术验证 | 可以作为主要依据 |
| B | 行业实践 | 可以作为重要参考 |
| C | 专家经验 | 需要结合其他证据 |
| D | 类比推测 | 仅作启发，需要验证 |
| E | 未经证实 | 不作为决策依据 |

### 示例：评估玩法推荐

```
推荐：邀请裂变

证据来源：
- Dropbox案例 (evidence_tier: B) - 双边奖励，K因子1.2
- 拼多多案例 (evidence_tier: B) - 社交裂变，快速增长
- 行业基准 (evidence_tier: B) - SaaS行业平均K因子0.8

结论：推荐可信度高（B级证据支撑）
```

## 安全边界最佳实践

### 识别高风险场景

当请求涉及以下领域时，系统会触发安全边界：

| 场景 | 触发词 | 正确做法 |
|------|--------|----------|
| 财务决策 | 投资、融资、估值 | 咨询财务顾问，系统仅提供框架 |
| 法律问题 | 合规、合同、知识产权 | 咨询律师，系统仅提供清单 |
| 监管合规 | 牌照、数据保护 | 咨询专业机构，系统仅提供检查项 |
| 组织变革 | 裁员、架构调整 | 咨询HR顾问，系统仅提供分析框架 |

### 正确使用安全边界响应

**系统输出示例**：
```
⚠️ 财务风险提示
本分析为决策支持框架，不构成最终投资建议。
重大财务决策建议咨询：注册会计师、投资顾问、法务顾问

置信度调整：原置信度 High → 调整为 Medium（安全边界限制）
```

**正确做法**：
1. 将系统分析作为起点，不是终点
2. 咨询专业顾问验证关键假设
3. 采用可逆的小实验验证

## 输出契约最佳实践

### 理解标准报告结构

每个报告都包含10个必选章节：

| 章节 | 用户友好标题 | 内容 |
|------|-------------|------|
| conclusion | 先看结论 | 最该先解决什么 + 置信度 |
| current_state | 先把现状说清楚 | 目标、阶段、约束、资源 |
| clarity_assessment | 现状够不够清楚 | 清晰度评分 + 缺失信息 |
| decision_process | 判断过程 | 候选方案对比 |
| recommendation | 推荐方案 | 方案 + 理由 + 路径 |
| resource_allocation | 资源分配 | 主攻线/次要线/监控线 |
| actions | 接下来怎么做 | 1-3个突破行动 |
| projection | 做完以后可能怎样 | 概率区间 + 敏感性 |
| review_trigger | 什么时候回头看 | 复盘时间 + 转移信号 |
| caveats | 注意事项 | 风险警告 + 不确定性 |

### 事实标记使用

在输出中正确标记事实来源：

```
当前状态：
- DAU: 1200 (observed) - 后台数据
- 转化率: 约3.5% (estimated) - 基于样本计算
- 竞品预算: 约是我们的2倍 (assumed) - 基于招聘信息推测
```

## 输出使用最佳实践

### 决策落地流程

```
1. 阅读执行摘要 → 快速理解建议

2. 理解因果链 → 确认逻辑合理

3. 评估风险 → 做好风险预案

4. 确认资源 → 确保有资源支持

5. 设计实验 → 小规模验证

6. 记录决策 → 便于后续追踪
```

### 风险预案

每个风险都应该有预案：

| 风险 | 概率 | 预案 |
|------|------|------|
| 低质量用户 | 高 | 设置质量门槛 |
| 预算超支 | 中 | 预留20%缓冲 |
| 技术延期 | 中 | 分阶段上线 |

### 实验设计

遵循最小可行实验原则：

```
假设：邀请裂变能提升K因子到1.2

实验设计：
- 范围：10%用户
- 周期：2周
- 成功标准：K因子 > 1.0
- 失败标准：K因子 < 0.8

决策规则：
- 成功：全量推广
- 失败：分析原因，调整方案
```

## 追踪最佳实践

### 关键时间点

| 时间点 | 追踪内容 |
|--------|----------|
| 1周 | 初步进展、问题 |
| 1月 | 指标变化、偏差 |
| 3月 | 效果评估、经验总结 |

### 偏差分析

预测偏差是正常的，关键是学习：

```
预测：K因子 1.2
实际：K因子 0.9
偏差：25%

原因分析：
1. 高估了用户分享意愿
2. 奖励吸引力不足
3. 分享流程有摩擦

改进：
1. 下次预测K因子时下调15%
2. 增加用户调研验证分享意愿
```

## 常见错误避免

### 1. 过度依赖单一案例

每个产品都有自己的特性，不能简单照抄。

### 2. 忽略风险

Skeptic Agent指出的风险往往是真实会发生的。

### 3. 证据不足就决策

置信度Low时，应该先做研究或小实验。

### 4. 忽略资源约束

再好的策略，没有资源支持也无法执行。

### 5. 不追踪结果

不追踪就无法学习和改进。

## 进阶技巧

### 1. A/B测试设计

```
/growth-master-skill design --test

请帮我设计一个A/B测试：
- 测试目标：验证邀请裂变效果
- 对照组：无奖励
- 实验组：双边奖励各20元
- 样本量：每组1000用户
- 周期：2周
```

### 2. 多方案对比

```
/growth-master-skill assess --compare

方案A：邀请裂变，预算5万
方案B：内容营销，预算5万
方案C：付费广告，预算5万

请对比这三个方案的ROI
```

### 3. 长期策略规划

```
/growth-master-skill design --roadmap

请帮我规划未来12个月的增长路线图：
- Q1：冷启动
- Q2：增长期
- Q3：规模化
```

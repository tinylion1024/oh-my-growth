# v1.0 Planning Archive

This directory preserves historical planning artifacts from the v1.0 buildout.
They are **not** the active project backlog.

Canonical live status now lives in:

- `docs/optimization-status.md`
- `CHANGELOG.md`
- `RELEASE_NOTES.md`
- `COMPLETION-REPORT.md`
- `scripts/release-check.sh`

The archived checklists may contain unchecked items, old command names, stale JSON
field names, or historical acceptance criteria that have been superseded by the
current v1.0.1+ validation suite.

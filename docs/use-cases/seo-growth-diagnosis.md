# SEO / AEO Growth Diagnosis Use Case

Use this page when a team wants organic acquisition from search and answer engines, not just more content volume.

## Problem

Search traffic is low, or organic visitors do not convert into high-intent signups. The likely issue may be positioning, intent mapping, page structure, or conversion path quality.

## Command

```bash
growth design "我们的网站自然搜索流量少，需要做 SEO 和 AEO 获客" \
  --industry saas \
  --stage 1-10 \
  --problem acquisition \
  --metric 新增高意向注册 \
  --view decision-memo
```

## Expected Output

- `SEO/AEO 获客系统` appears in `reference_method_packs`
- priority ranking favors actions tied to intent and conversion
- measurement notes include search visibility, source attribution, and signup quality
- stop signals warn against scaling low-quality content

## Practical Experiment

1. Select 10 high-intent queries with clear commercial or problem-aware intent.
2. Map each query to one page, one answer promise, and one conversion action.
3. Add concise answer blocks, comparison sections, FAQs, and internal links.
4. Track impressions, qualified clicks, signup rate, activation quality, and assisted conversions.

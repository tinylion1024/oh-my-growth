# 标签体系规范

## 标签维度

| 维度 | 说明 | 标准值 |
|------|------|--------|
| **行业** | 所在赛道 | 电商、社交、金融、教育、出海、本地生活、工具、SaaS、AI |
| **玩法** | 核心增长策略 | 裂变、会员、内容营销、补贴、算法推荐、订阅、DTC、社区、口碑、游戏化 |
| **模式** | 商业模式 | 平台、Marketplace、DTC、订阅、SaaS、免费+付费 |
| **市场** | 地域 | 中国、海外、全球 |
| **阶段** | 企业阶段 | 起步、增长、成熟 |

## 标签分类扩展

### AI产品类标签
| 标签 | 说明 | 适用案例 |
|------|------|----------|
| AI | 人工智能产品 | DeepSeek、ChatGPT、Claude |
| 大模型 | 大语言模型 | GPT-4、Claude、DeepSeek-V3 |
| AIGC | AI生成内容 | Midjourney、Suno、Runway |
| AI编辑器 | AI辅助编程 | Cursor、GitHub Copilot、Windsurf |
| AI搜索 | AI驱动搜索 | Perplexity、秘塔AI搜索 |
| AI助手 | AI对话助手 | ChatGPT、Claude、Kimi、豆包 |

### 内容类标签
| 标签 | 说明 | 适用案例 |
|------|------|----------|
| 短视频 | 短视频平台 | 抖音、快手、TikTok |
| 直播 | 直播电商/娱乐 | 淘宝直播、抖音直播 |
| UGC | 用户生成内容 | 小红书、B站、抖音 |

### 策略类标签
| 标签 | 说明 | 适用案例 |
|------|------|----------|
| 游戏化 | 游戏化增长策略 | 蚂蚁森林、抖音极速版、Duolingo |
| 裂变 | 社交裂变增长 | 拼多多、微信红包、Dropbox |
| 订阅 | 订阅制商业模式 | Netflix、Spotify、Notion |

## 标签示例

```
案例: 拼多多
标签: 电商, 社交裂变, 拼团, 下沉市场

案例: SHEIN
标签: 快时尚, 内容营销, KOC, 出海, DTC

案例: Zoom
标签: SaaS, 工具, 病毒传播, 免费获客

案例: 微信红包
标签: 支付, 社交裂变, 绑定银行卡, 红包

案例: 蚂蚁森林
标签: 金融, 游戏化, 公益, 环保
```

## 使用方式

每个案例建议添加3-5个标签，优先选择最核心的标签。

- 再看 [用户旅程诊断](./user-journey-diagnosis.md)

### 当你已经知道问题，但还没想好策略

- 先看 [增长策略环](./growth-loop.md)
- 再看 [实验设计](./experiment-design.md)

### 当你需要进入获客和投放

- 先看 [AIDA转化模型](./aida-model.md)
- 再看 [归因与身份识别](./attribution-and-identity.md)

## 和项目的关系

这些指南不是额外的独立课程，而是项目内部的通用增长判断层：

- `references/` 更偏 skill 工作流和输出契约
- `knowledge/guides/` 更偏增长经营知识本体
- `knowledge/weapons/` 更偏具体打法
- `knowledge/cases/` 更偏案例证据
